# Conrad Challenge 参赛资料与学习笔记

[进入网站](https://wenxilian.github.io/conrad-team-hub/)

我是 Thomas Lian，目前是华师大附中十年级的学生。关注到 Conrad Challenge 后，我想先了解参赛方式、费用和准备要求，再决定自己是否参加。

查阅资料时，往届许多有意思的项目给了我启发。我把赛事信息、项目案例和相关知识整理成这个小网站，分享给同样感兴趣的同学，也方便与家长、老师一起讨论。

## 网站里有什么

- **开始阅读与认识赛事**：阅读路线、报名判断、赛制、时间、费用及提交要求。
- **历届获奖项目**：2024–2026 年的 13 个案例，介绍背景、技术方案、验证问题与商业思路。
- **工程与技术能力**：编程、机电控制、无人机、机器人、原型与测试方法。
- **商业计划与市场验证**：五种商业模式、用户访谈、市场规模、成本、定价与财务算例。
- **团队与项目执行**：学生和导师的职责、协作记录、时间安排、安全、保密与知识产权。
- **资料与工具箱**：官方来源、空白模板、图表和交互计算器。

可以先从 [网站首页](https://wenxilian.github.io/conrad-team-hub/) 选择阅读入口，也可以直接浏览 [往届项目](https://wenxilian.github.io/conrad-team-hub/02-projects/index.html)。详细案例、表格和公式都保留在相应专题中，不必一次读完。

## 关于资料

这是我在了解赛事过程中整理的学习资料。官方要求、团队公开申报与教学模拟分别注明；它们不代表我已经参赛或完成了相关实验。报名时请再核对本届官方通知。
