# 队伍职责、选拔与会议节奏

> 资料性质：本项目建议 / 教学分析。整理与核查日期：2026-10-12。本站为非官方独立学习资料。

学生团队按目标赛季规则核查人数与年龄 (曾讨论 2–5 人、13–18 岁)。建议工程结构/机械、软件与数据、实验验证、市场商业、英文传播五类职能，根据 3–5 人的实际人数交叉安排。不要以五个岗位必须分别对应五个人为前提。

学生选拔时设实际小任务：技术候选人读取公开传感器数据并绘图或解释已有结构，商业候选人搜集两个真实竞品并说明价格与维护费，写作候选人以英语表达一段包含数据来源的论证。考察持续投入、沟通和质量意识，而不单看奖项或竞赛经历。

**管理节奏**：每周学生会议，汇报已完成文件、问题和下一周任务；每两周一次导师审查，不代替学生项目决策。每个任务记录负责人、交付文件、测试证据、预计完成日。家庭可以先选择每周可投入时间区间，而不披露详细私人日程。
