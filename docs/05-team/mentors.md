# 成人导师：指导、资源与学生主导

> 资料性质：本项目建议 / 教学分析。整理与核查日期：2026-10-12。本站为非官方独立学习资料。

具不同专长的成人导师可以提供指导与资源，学生应负责实际项目及提交材料。

辅导通常可包括：讲授研究方法、示范如何设计客户访谈、帮助获取合规的测试资源、提供安全监督、检查公式/分析的逻辑、评论英文初稿、模拟答辩。但学生应主导研究问题、设计、实施、数据分析、具体提交文稿和展示。规则细节、coach 许可范围、AI 工具与成人参与边界须依照当届官网原文核查，不能把底稿的解释直接写成官方逐项许可清单。

典型边界问题：
- 家长能提出「应分析 TAM/SAM/SOM」的框架，但不宜代学生完成全部市场数据与结论。
- 工程师家长可讲授控制与安全，不宜把成人事先完成的核心结构包装成学生独立发明。
- 学生可用开源代码和 AI 辅助，但须遵循当届的披露、署名和原创性规定，能解释代码做什么。
- 商业分析里的数值与仿真表若由成人做出、学生无法推导，现场 Q&A 风险明显。
- 如果已有前期成果，应清点学生、成人、学校/实验室各自贡献，以及 IP 权属。

建议内部使用工程/商业任务记录、Git 提交、实验日志、导师反馈和学生决策记录；评委可能在现场追问逻辑与来源，但**没有可核实依据时不能声称赛事有某种强制日志检查机制**。

商业学习可安排约 20–30 小时：市场用户研究、微观经济与基础财务、商业模式、英文表达和答辩。具体时长是教学建议。
