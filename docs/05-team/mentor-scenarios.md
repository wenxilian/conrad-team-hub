# 家长指导的具体边界

完整上下文已合并到 [连续阅读章节](mentors.md#scenarios)，本页保留原链接兼容。

> 资料性质：本项目建议 / 教学分析。整理与核查日期：2026-10-12。本站为非官方独立学习资料。

### 可以合理提供的支持

- 商业导师讲授 TAM/SAM/SOM、固定和可变成本、市场调查伦理、盈亏平衡等，给学生提建议并指出公式或口径错误。
- 工程导师传授安全规范、介绍 CAD/控制基本方法、示范仪器测量，帮助获取安全场地与公共资料。
- 家长联系潜在访谈对象、协调设备采购和场地，但访谈问题、数据整理和最终结论由学生执行。
- 导师阅读学生撰写的 Innovation Brief，指出未解释的数字和自相矛盾的论证，学生自行修订。

### 存在明显边界风险的做法

- 成人实际设计核心技术，学生只在表面上运行现成软件，仍宣称为学生原创。
- 家长代做全部市场调查、财务模型或英文商业文字；学生只负责排版和背稿。
- 工程顾问完成实物功能与测试，学生无法解释传感器、控制机制及数据来源。
- 为使项目看起来完美，仅选取一次成功演示而隐瞒失败、虚构访谈或改造原始数据。

应依据目标赛季的官方规则确定具体限制，而不是把上述教学建议说成组委会原话。**项目团队最好设立 `student-contribution-log`，每次学生实际完成任务后才更新，导师只写其指导和反馈，禁止事后编造。**

### 组委会如何发现成人代做？

现场答辩的技术细节、数字来源、实际失败案例、开发决策追问可能揭示学生是否熟悉项目。提交材料的一致性、过程证据及学术诚信申报也可能有帮助。但不能断言组委会必然有某种自动查重、全过程审计或随机访谈机制，除非在官方规则中查证。正确做法是让项目真实由学生主导，不要把留下证据理解为「应付检查」。
