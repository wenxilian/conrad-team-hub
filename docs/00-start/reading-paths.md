# 家长与学生的两条阅读路线

在了解 Conrad Challenge 时，我发现同学和家长往往会从不同的问题开始：同学想知道可以做什么，家长更关心时间、费用和准备条件。我把这两条阅读路线整理在这里，方便大家从自己关心的内容读起。

如果已经有感兴趣的方向，也可以直接进入相应的工程、商业或案例页面，再回来查看赛事要求。


| 阅读阶段 | 家长重点 | 学生重点 |
|---|---|---|
| 判断投入 | 资格、时间、费用、安全 | 感兴趣的问题和可验证创新 |
| 理解项目 | 案例的证据边界与采购者 | 技术管线、程序和实验指标 |
| 组织执行 | 资源、贡献、权属和导师边界 | 每周交付、日志、失败复盘 |
| 准备提交 | 公开审核与预算 | 英文文书、数字来源及独立答辩 |

长页保留原有案例、算例、表格与问答。无需一次读完全部页面；每页目录和延伸阅读支持从具体困惑出发。
