# 家长与学生的两条阅读路线

> 资料性质：阅读建议。整理与核查日期：2026-10-12。本站为非官方独立学习资料。

家长建议从赛事规则、时间和费用开始，再看案例、成人边界与报名决策；学生建议从案例进入技术、商业、测试及表达训练。

| 阅读阶段 | 家长重点 | 学生重点 |
|---|---|---|
| 判断投入 | 资格、时间、费用、安全 | 感兴趣的问题和可验证创新 |
| 理解项目 | 案例的证据边界与采购者 | 技术管线、程序和实验指标 |
| 组织执行 | 资源、贡献、权属和导师边界 | 每周交付、日志、失败复盘 |
| 准备提交 | 公开审核与预算 | 英文文书、数字来源及独立答辩 |

长页保留原有案例、算例、表格与问答。无需一次读完全部页面；每页目录和延伸阅读支持从具体困惑出发。
