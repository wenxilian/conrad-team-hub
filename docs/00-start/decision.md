# 报名决策：时间、能力、预算与退出条件

我目前还在考虑是否参加 Conrad Challenge。除了对项目有兴趣，我也想弄清楚自己能投入多少时间，需要补哪些能力，以及家人和老师能提供哪些支持。

下面整理了报名之前可以一起讨论的问题和步骤。对我来说，先试着缩小选题、了解用户和验证一个想法，再决定投入多大范围，会比一开始就承诺完成一个复杂项目更踏实。
