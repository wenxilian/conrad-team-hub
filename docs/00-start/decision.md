# 报名决策：时间、能力、预算与退出条件

> 资料性质：项目建议。整理与核查日期：2026-10-12。本站为非官方独立学习资料。

报名之前，家庭应共同确认目标赛道、实际成员、可投入时间、成人贡献边界与测试条件。奖项不能作为投入的唯一理由。

1. **Step 1**: 读本届规则，确认成员资格、锁定时间和报名渠道。
2. **Step 2**: 界定一个最小可验证创新，列出已有与仍需开发的部分。
3. **Step 3**: 分别访谈使用者、付款者和采购决策者，检查客户假设。
4. **Step 4**: 列材料、返工、测试、报名、差旅与运输预算，设上限。
5. **Step 5**: 安排每周学生会议与两周导师评审，准备失败时的收缩或暂停条件。

能够取得工程证据、用户反馈、英文表达与合作经验，即使没有获奖仍可能值得继续；若核心成果只能由成人完成、没有安全场地或权属不清，应先解决这些约束。
