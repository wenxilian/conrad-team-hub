# 报名决策：时间、能力、预算与退出条件

参加比赛会占用学生的时间，也需要家庭和老师提供持续支持。我们可以先一起讨论：这次最想获得什么经验，已有能力能够支撑哪个方向，以及能接受多少时间和预算投入。

下面的步骤帮助大家把这些想法落到具体条件上。报名决定可以随着试验和访谈逐步变得清晰，不必在选题还很模糊时就承诺完成一个很大的项目。
