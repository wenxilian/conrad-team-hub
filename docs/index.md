# Conrad Challenge<br>团队参赛与创新实践指南

我们把这份资料放在一起，是为了让家长、学生和指导老师能围绕同一批问题展开讨论：这项比赛需要投入什么？学生能把一个想法做到什么程度？除了做出原型，还要怎样证明它有人愿意使用、有人愿意付费？

这里既有赛事规则和往届项目，也有工程测试、商业分析、团队分工和执行计划。大家可以先浏览下面的栏目介绍，再选一条与自己当前任务有关的阅读路线。主要专题采用连续的长篇讲义；案例各有独立页面，方便在讨论时分享。

## 怎样开始读

**如果你是家长或指导老师**，可以先读 [报名决策](00-start/decision.md) 和 [完整赛事指南](01-overview/introduction.md)，再选两三个案例。这样，我们讨论投入和支持方式时，就能有一个具体的项目参照。

**如果你是准备参赛的学生**，可以先从 [获奖项目导览](02-projects/index.md) 找一个自己感兴趣的问题。读完案例后，再回到工程与商业两部分：我们需要做出什么、测量什么，又需要向哪些用户提问？

已有项目方向的团队，可以直接进入 [家庭硬件六周实践](04-business/household-hardware.md)，或尝试 [财务模拟器](04-business/calculators.md)。这些工具里的假设数字可以调整，但正式项目的结论仍需要来自自己的访谈、报价和实验。

## 阅读时如何看待数字和结论

赛事要求以本届官方指南为准；获奖项目的性能与商业预测，按团队公开申报注明来源；我们用于练习的算例和测试方案，标为教学模拟或建议。读到一个有吸引力的数字时，可以顺着来源进一步查看它的条件与依据。
