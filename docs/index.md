# Conrad Challenge<br>参赛资料与学习笔记

我是 Thomas Lian，目前是华师大附中十年级的学生。最近关注到 Conrad Challenge，我想先了解它的参赛方式、费用和准备要求，再决定自己是否参加。

查资料时，我发现往届有不少很有意思的项目。从净水设备到卫星控制，再到蜂群健康分析，这些项目给了我很多启发，也让我想进一步了解它们背后的技术和商业思路。于是，我把找到的资料和学习时的问题整理成这个小网站，分享给同样感兴趣的同学，也方便和家长、老师一起讨论。

这里保留了比较详细的案例、算例和图表。大家不必一次读完，可以从下面的栏目中选一个感兴趣的入口。

## 怎样开始读

如果你也在考虑是否参加，我建议先读 [报名决策](00-start/decision.md) 和 [完整赛事指南](01-overview/introduction.md)，了解时间、费用与准备要求，再选两三个案例看看。

如果你更想知道学生可以做出什么，可以直接打开 [获奖项目导览](02-projects/index.md)。找到感兴趣的方向后，再阅读工程和商业专题，看看需要学什么、验证什么。

家长和老师可以结合 [团队与导师](05-team/mentors.md)，与同学讨论支持方式。已有项目想法的同学，也可以参考 [家庭硬件六周实践](04-business/household-hardware.md) 或试用 [财务模拟器](04-business/calculators.md)。
