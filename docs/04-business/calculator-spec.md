# 财务模拟器的参数与适用边界

完整上下文已合并到 [连续阅读章节](household-hardware.md#model-limits)，本页保留原链接兼容。

- 页面标题：家庭购买决策模拟器。
- 滑块一：购买安装价 $P$，默认 600 元，可调 100–2000 元，步长 50。
- 滑块二：年度净节约 $S$，默认 240 元，可调 20–600 元，步长 20。
- 滑块三：使用寿命 $T$，默认 5 年，可调 1–10 年，步长 1。
- 即时展示 $P/S$ 和 $TS-P$，并显示回收期是否早于寿命期。
- 累计成本图应严格说明是否已扣除两方案共有的成本；最严谨方式是绘制真实基准方案 $C_{0}$ 与新方案 $P+C_{1}$ 的累计成本。若仅用 $tS$ 与 $P$ 两条线，应标为差额比较示意。
- 另一个页面可展示销售盈亏平衡，参数 $P=150$ 美元、$VC_{u}=90$ 美元、$F=12,000$ 美元，销量 0–600 件，默认 300，临界 200；不得误称利润为收入。
- 脱网运行、移动端可操作、打印时显示当前所选参数与结果。
