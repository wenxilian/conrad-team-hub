# 2024–2026 获奖项目导览

一个参赛项目究竟要做到多深，单看规则往往没有直观答案。往届项目能提供具体参照：有的从用水和维护问题切入，有的改进控制与通信，还有的把数据分析用于农业或医疗。我们读这些案例，是想看清它们如何连接用户问题、技术方案和商业价值。

下面列出 13 个项目。每个项目的背景、技术拆解、实验建议和商业分析都放在独立页面中；这里帮助大家选择阅读入口。

## 先选一个与你关心的问题接近的案例

- **想做贴近日常使用场景的硬件**：可以从 [Soaring Seeds](soaring-seeds.md) 的净水维护问题，或 [Aquabel](aquabel.md) 的节水方案开始，看看使用者与采购者为什么可能关心不同的指标。
- **对编程、控制或机器人感兴趣**：可以对照 [Aphelion](aphelion.md)、[FireAIDSS](fireaidss.md) 和 [RescueBot](rescuebot.md)，再阅读 [工程与技术能力](../03-engineering/programming.md)。
- **想理解商业价值怎么写**：可以读 [BeeGuard](beeguard.md) 的订阅思路和 [DiveGuard](diveguard.md) 的水下通信，再进入对应的 [BeeGuard 商业分析](../04-business/beeguard-case.md) 与 [DiveGuard 市场分析](../04-business/diveguard-case.md)。
- **对数据、材料或行业应用感兴趣**：可以浏览 [OncoMap](oncomap.md)、[ChitoClear](chitoclear.md)、[SensAir](sensair.md) 和 [AeroLattice](aerolattice.md)，留意它们需要怎样的专业资源和验证条件。
