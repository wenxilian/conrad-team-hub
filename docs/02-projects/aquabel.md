# Aquabel：节水方案如何进入实际采购

Aquabel 围绕公共厕所用水提出方案，让我想到：节水效果之外，安装、维修和设备寿命也会影响采购决定。使用者、维护者和付款者可能并不是同一群人。

这里保留项目介绍与公开申报，再讨论节约量和成本怎样验证。准备类似硬件项目的同学，可以带着这些问题再看自己的使用场景。

## 官方记录

2025，ToiletWarrior，中国，Water Challenge Pete Conrad Scholars；22万升/单台/年、85%费用下降为公共厕所情境团队申报。来源：[年度获奖档案](https://conrad.spacecenter.org/2025-winners/)，核查于 2026-10-12。

## 背景、技术与申报边界

讨论中提到一款智能节水小便器，团队声称单台设备每年节约约 220,000 L 水、降低约 85% 相关运营成本。展示时应先查是否针对公共设施、某种使用频率及特定基准，绝不能直接推广为每个家庭能够节约这些数字。教学价值在于「运营成本节省—新增投资—回收期」链条。

## 可执行的教学分析

以下为教学建议，未宣称获奖团队已经实施。目标客户：公共厕所运营方、物业与设施管理部门，不能把公共设施用量套给每户家庭。

验证设计：比较相同使用频率下的水量、耗材与维护，报告基准设施、计量周期和故障情境。22 万升及 85% 是团队申报，未独立验证。

商业路线：购置费、安装停用、年度净节约与寿命应放同一张 TCO 表中；回收期例子是教学模拟。
