# ChitoClear：把材料创新放进净水场景

材料创新要产生实际价值，需要回答材料从哪里来、怎样加工，以及在使用后如何处理。ChitoClear 是 Aquaneers 团队 Shells for Water 项目中的净水产品，为我们提供了一个连接材料与水处理的例子。

下面保留其技术与商业介绍，并讨论过滤表现、成本和使用条件如何比较。阅读时可以留意实验指标，也可以思考不同地区的家庭、企业和机构是否有相同需求。

## 背景、技术与申报边界

壳聚糖水净化利用废弃海产品资源，受益者可能是农村家庭，实际采购者却可能是机构或公共项目。对这类产品，单靠用户满意度不能证明商业可持续，要调查机构预算、维护要求和付款机制。

## 可执行的教学分析

以下为教学建议，未宣称获奖团队已经实施。目标客户：终端居民、机构采购者与公共项目受益者。

验证设计：比较统一水质和剂量下的处理效果，记录单位处理成本、原料批次与残余物处置，不能只用废物再利用口号论证安全。

商业路线：分别调查使用者、付款者和维护负责人，核查预算与采购标准。
