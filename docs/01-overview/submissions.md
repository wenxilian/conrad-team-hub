# Innovation Brief、视频、网站与评分

> 资料性质：官方规定 + 教学分析。整理与核查日期：2026-10-12。本站为非官方独立学习资料。

## 2026–2027 正式要求

Brief 总上限 3,000 英文词。以下分节上限合计也是 3,000 词，参考资料另按平台要求提交。

| 章节 | 上限 (英文词) |
|---|---:|
| Elevator Pitch | 150 |
| Team | 150 |
| Opportunity | 300 |
| Key Metrics | 750 |
| Validation/Progress | 450 |
| Market | 300 |
| Competition | 300 |
| Go-To-Market | 150 |
| Business Model | 300 |
| Fundraising | 150 |

Innovation Video 为 3–5 分钟，应展示模型或原型；MP4 文件小于 800 MB，并提供可访问的 YouTube 或 Vimeo 链接。项目网站应能通过直接链接访问。本学习资料站不替代参赛队伍的产品网站。

评分权重：创新 30%，叙事与专业表达 20%，可实施性 20%，市场策略 20%，财务 10%。原型可用草图、3D 模型、故事板、线框或实体模型；表达应与实际成熟度一致。

来源：[2026–2027 Student Guide](https://conrad.spacecenter.org/wp-content/uploads/2026/08/2026-2027-Conrad-Challenge-Student-Guide-Official.pdf) 第 9–14 页，核查于 2026-10-12。

## 材料准备与原型成熟度

- Innovation Brief：给出 Opportunity、Innovation、Key Metrics、Validation 等技术商业论证，也包括市场、竞争、商业模式和融资要素。底稿引用某一赛季不超过 3,000 英文词的规则，并讨论商业五节合计约 1,200 词；**这些数字用于理解篇幅，但必须对照目标赛季正式 Student Guide 核查**。
- 创新视频：底稿提及 3–5 分钟的项目介绍。具体格式、文件限制、原型展示要求依赛季指南。
- 项目网站：可以展示介绍、团队、技术进展、应用和相关资料；保密内容不宜在公开网站直接披露。
- 全球决赛 Pitch：以学生独立讲解与回答问题为主。导师不应代替学生演示或回答。

原型可能是 CAD、结构样品、软件原型、可运行的关键功能装置、计算机仿真乃至功能更完整的集成设备。赛事不要求所有队伍拥有经过工业认证的成熟产品。反过来，采用概念或仿真原型的队伍不应虚构量产效果或真实部署表现。
