# RescueBot：状态机与封闭测试

完整上下文已合并到 [连续阅读章节](programming.md#rescuebot)，本页保留原链接兼容。

### 功能流程

1. 设备自检：测距传感器、编码器、电池与急停状态。
2. 接收目标距离与启动命令，检查安全条件。
3. 启动电机并累计里程，反复检查障碍物和异常数据。
4. 障碍、超时、定位异常或断连时立即安全停止。
5. 达到目标距离后停车并启动警示装置。
6. 保存全程数据用于复盘。

学生能独立解释每个条件和传感器依赖，比仅展示程序运行更有意义。

### 推荐测试表

| 条件 | 试验 | 指标 |
|---|---|---|
| 目标距离变化 | 多组预定距离 | 距离误差 |
| 障碍物 | 不同位置的模拟障碍 | 检出率、漏检率、制动距离 |
| 地面 | 平整、粗糙、低坡度安全区域 | 任务完成率 |
| 重复性 | 同设置运行 20 次 | 成功率、失败归因 |
| 供电 | 不同电池电量 | 持续可用时间 |
| 失效安全 | 人为模拟传感器缺失 | 是否停止并提示 |

假设 20 次完成 18 次，报告 90% 完成率，也要说明两次失败时的条件；单个样本的 90% 不能直接作为可靠性认证。**任何类似道路安全项目只能在封闭、授权场地测试，不在开放道路测试。**

## 状态机伪代码：教学逻辑

仅解释安全逻辑，不能直接用于实物。传感器、制动和急停需独立验证。

~~~text
状态 = IDLE
收到启动命令:
    检查电池、编码器、测距及急停
    如果自检不通过: 进入 FAULT，禁止驱动
    否则: 设置目标距离，进入 MOVING

每个控制周期:
    读取编码器、测距与状态
    如果急停触发、传感器断连、超时或障碍:
        关闭电机，进入 SAFE_STOP，记录故障
    否则如果累计距离达到目标:
        关闭电机，启动警示装置，进入 ARRIVED
    否则:
        限速驱动，记录时间、里程与传感器值

人工确认安全并复位:
    返回 IDLE；禁止故障后自动重启
~~~
