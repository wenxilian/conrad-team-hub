# 四级工程能力与评价边界

完整上下文已合并到 [连续阅读章节](programming.md#levels)，本页保留原链接兼容。

| 层级 | 能力 | 可交付成果 | 不能用什么替代 |
|---|---|---|---|
| L1 基础编程 | Python 函数、循环、文件和绘图 | 传感器数据读取、图形与基础脚本 | 演示别人写好的现成程序 |
| L2 工程编程 | 嵌入式 I/O、模块化与故障处理 | 单模块独立运行 | 只连线但不理解控制逻辑 |
| L3 系统集成 | 多模块交互、日志、测试 | 端到端可重复原型 | 一次剪辑后的视频 |
| L4 工程优化 | 对照、指标、复杂工况验证 | 有定量证据的改进 | 未披露基准的百分比提升 |

团队整体应以 L3 为合理目标；创新核心尽可能达到 L4。不要求每位学生掌握全部模块，但至少两人能够独立解释关键软件。分级是项目建议，**不是官方认证等级**。
