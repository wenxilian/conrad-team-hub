# 工程与商业术语

完整上下文已合并到 [连续阅读章节](source-method.md#glossary)，本页保留原链接兼容。

> 资料性质：术语解释。整理与核查日期：2026-10-12。本站为非官方独立学习资料。

| 术语 | 含义与容易混淆之处 |
|---|---|
| PoC | 概念验证，能运行不等于可靠 |
| Baseline / Benchmark | 基准方案与同条件对比 |
| PINN | 物理信息神经网络，提到名称不等于完成验证 |
| PID | 比例、积分、微分控制 |
| BOM | 物料清单，原型成本不等于量产和售后总成本 |
| TCO | 总拥有成本，须说明年限、贴现与残值 |
| TAM / SAM / SOM | 总体、可服务、可获得市场，需统一口径 |
| Contribution | 边际贡献，尚未扣固定成本 |
| SaaS | 软件服务订阅，注册用户不等于付费用户 |
| Gate | 阶段评审，可决定继续、收缩或暂停 |
| Coach | 成人指导者，不代替学生完成材料 |
| Innovation Brief | 当届指定章节和词数的创新说明 |

资料边界与更正记录见 [来源核查](source-method.md)。
