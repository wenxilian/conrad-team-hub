# 访谈、成本、实验与答辩空白模板

了解访谈和实验怎么做之后，我把常用的记录字段整理成了这些空白模板。准备类似项目的同学可以下载，再按自己的问题修改，不必每次都从空白表格开始。

模板没有预填真实数据。填写后的个人信息和未公开技术，应保存在团队自己的受控空间；共享讨论时尽量使用匿名记录。


- [匿名访谈字段](../downloads/interview.csv)。
- [竞品与三年 TCO](../downloads/competitor.csv)。
- [BOM 与报价来源](../downloads/bom.csv)。
- [实验与失败日志](../downloads/experiment.csv)。
- [学生贡献与成人支持](../downloads/contribution.csv)。
- [风险台账](../downloads/risk.csv)。
- [Lean Canvas 工作表](../downloads/lean-canvas.md.txt)。
- [四页商业 Pitch 与七个问题](../downloads/pitch.md.txt)。

正文保留访谈九问、WP1–WP5 与六周课表；模板支持记录，不替代真实调查。正式 Canvas 在当届平台包含 12 问，词数要求以官方指南为准。
